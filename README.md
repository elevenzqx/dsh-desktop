# DSH Desktop

macOS 菜单栏应用，一键管理本机 dsh Web（`http://127.0.0.1:3080/`），并将其作为
**常用的 AI 网站导航工具**：内置一个带**左侧快捷侧边栏 + 动态标签页**的简易浏览器窗口。

- ▶ **启动 dsh Web**：以绝对路径的 node 拉起 `dsh web`，端口就绪后**自动用应用全屏窗口打开页面**（不再打开外部浏览器）
- ↻ **重启 / ⏹ 停止**：重启先停后起；停止会终止进程并按端口 3080 兜底清理
- 🧭 **AI 导航窗口（内置浏览器，默认全屏）**：原生 WKWebView（自家窗口，无需辅助功能授权，绿按钮 / ⌃⌘F 随时切换）
  - **左侧窄侧边栏**：一排彩色快捷按钮直接打开 AI 网页——
    豆包、DeepSeek、阿里千问、百度、腾讯元宝，以及 DSH 插件、DeepSeek 费用、硅基流动费用，
    图标为各官网真实 favicon（内置打包，可在设置中重新抓取）；
    ⚙ **最下方为设置按钮**：点击后**主画布切换为配置页**（左侧分区导航，后续可扩展更多配置分区），
    支持对快捷栏目增删、改名称/网址/**tips 悬停提示**/图标（SF Symbol 或抓取官网图标）/颜色、排序、恢复默认；
    配置页右上角「完成」、再点设置按钮或点击任意快捷栏目/标签即返回浏览。
    主页（DSH Web）按钮固定，其余栏目均可自由配置。
  - **顶部固定标签栏**（高度小巧）：每个快捷页一个标签，**切换页面不关闭**（各标签独立保留浏览状态），
    每个标签可**单独关闭以释放资源**；含后退 / 前进 / 刷新 / 外部浏览器 / 全屏按钮
  - 支持 **⌘C/⌘V/⌘X/⌘A** 复制粘贴快捷键（编辑菜单 + 按键兜底双重保障）
  - 支持**缩放（最大化）**：标题栏双击、绿按钮（⌥ 点击）或菜单「缩放」放大到 macOS 可用屏幕
- ⚡ **快捷页面菜单**（状态栏菜单 ▸ 快捷页面，跟随设置里的快捷栏目实时更新）
- ♻️ **菜单刷新**：状态菜单「刷新页面」或主菜单 ⌘R，刷新当前标签
- 📦 **安装 dsh 插件…**：弹出命令窗口，预填 `dsh plugin --profile web add <npm 包名>`，任意改可执行
- 💻 **执行任意命令…**：zsh 执行任意命令，输出实时滚动显示（带历史、停止、退出码/耗时）
- 📄 **打开 Web 日志**：`dsh web` 输出写入 `~/Library/Logs/dsh-desktop-web.log`
- 🚪 **退出不关后台**：退出 DSH Desktop 时**保留 dsh web 后台继续运行**（不再主动停止）

技术栈：原生 Swift + AppKit（含 WebKit），零第三方依赖，`swiftc` 编译（`Sources/main.swift` +
`Sources/browser.swift`），不打包安装器。菜单栏图标实时反映运行状态（● 运行中 / ○ 未运行），并显示 pid。

## 构建与安装

```bash
./build.sh                 # 产物: build/DSHDesktop.app（构建时自动写入本机 node/dsh 绝对路径）
cp -R build/DSHDesktop.app /Applications/
open /Applications/DSHDesktop.app
```

卸载：`rm -rf /Applications/DSHDesktop.app`（应用只写一个日志文件，无其他残留）。

## 注意事项

- 应用是纯菜单栏应用（`LSUIElement`），不占 Dock；菜单栏图标即入口。
- 若 3080 端口已在运行（说明已有 dsh web 在跑），**启动应用时自动打开全屏窗口**；点「启动」也会识别并直接打开窗口。
- **退出应用不会停止 dsh Web**：无论 dsh Web 是否由本应用启动，退出时都保留后台运行。
- 从 Finder 启动的应用 PATH 很窄，因此构建时把 node/dsh 的绝对路径写入 Bundle（`Resources/dsh-paths.json`）——
  更新/迁移 node 后请重新运行 `./build.sh`。
- 侧边栏快捷栏目配置持久化在 UserDefaults（`dshDesktop.shortcuts.v1`），跨启动保留。
